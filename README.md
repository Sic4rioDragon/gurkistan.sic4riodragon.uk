# Gurkistanischer Internetschein Generator

Auf der Seite kann man eine Vorlage auswählen, eigene Daten eintragen, ein Profilbild hochladen und das fertige Bild als PNG herunterladen.

Die Idee dazu kam durch dieses Video:

https://www.youtube.com/shorts/iJme3FOMCnQ

- https://www.reddit.com/r/gurkistan/comments/1tarstn/internetf%C3%BChrerschein_zum_abholen/ (Wurde bestätigt das ich es brauchen kann)
